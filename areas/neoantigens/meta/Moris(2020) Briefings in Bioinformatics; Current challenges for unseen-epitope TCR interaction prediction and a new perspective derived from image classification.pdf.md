## Abstract

An examination of why generic TCR-epitope recognition prediction remains unsolved, focusing on validation strategies that distinguish performance on seen from unseen epitopes. It introduces ImRex, which represents a TCR-epitope pair as an interaction map of pairwise physicochemical properties for a convolutional network, and catalogues data problems specific to this task.

## Summary

This is the paper that named the problem the later work in this collection quantifies. Methods can predict recognition for a specific set of epitopes; evaluating all possible TCR-epitope pairs is a different task, and reporting one number over both conceals the failure.

The ImRex representation is a genuinely different idea: rather than concatenating two sequences, build a 2-D interaction map from pairwise amino acid physicochemical properties, so the network sees the combination as an image with spatial structure.

## Key points

- Separates validation on seen epitopes from unseen epitopes as a methodological requirement, not a detail.
- ImRex represents the pair as a pairwise physicochemical interaction map rather than concatenated sequences.
- Catalogues the field's data problems: negative-data selection, class imbalance, and epitope-frequency skew.
- Anticipates by several years the generalisation failures Culka (2026) and Jensen (2024) measure.

## Limitations

The authors describe rather than solve the unseen-epitope problem, and ImRex does not close it. They use only CDR3 and epitope sequence, discarding all other VDJdb metadata including V and J genes, and apply no filtering on VDJdb confidence scores, so training labels vary in reliability. Negatives are generated by pairing against 248,895 CDR3s from healthy repertoires, which assumes non-binding rather than measuring it.
