# robots.txt for this host. Governs the WHOLE site (/, /gol/, /venn/, /paperlib/),
# not just PaperLib -- robots.txt only has meaning at the root, so it cannot be
# scoped to one project. Install it with:
#
#     sudo install -m 644 robots.txt /var/www/html/robots.txt
#
# ---------------------------------------------------------------------------
# WHY `User-agent: *` HAS NO `Disallow` BELOW, AND MUST NOT GROW ONE
# ---------------------------------------------------------------------------
# /paperlib/ is kept out of search indexes by `X-Robots-Tag: noindex, nofollow,
# noarchive, nosnippet` on every page, every PDF and every digest, plus a robots
# meta tag on the HTML.
#
# Adding `Disallow: /paperlib/` here would WEAKEN that, not strengthen it. A
# disallowed URL is never fetched, so the crawler never receives the noindex --
# and a URL it may not fetch can still be listed, bare, on the strength of a
# link from somewhere else. Allowing the fetch and answering with noindex is
# what actually keeps it out. Do not "tighten" this by adding a Disallow.
#
# ---------------------------------------------------------------------------
# WHY THE NAMED AGENTS BELOW *ARE* DISALLOWED
# ---------------------------------------------------------------------------
# The reasoning above holds for crawlers that want to build a search index,
# because they read `X-Robots-Tag`. Crawlers that collect text to train or
# ground a model do not: for them `noindex` means nothing and `Disallow` is the
# only signal there is. So the two groups get opposite treatment on purpose --
# search engines are invited to fetch and told not to index; model crawlers are
# asked not to fetch at all.
#
# Two of these are not crawlers. `Google-Extended` and `Applebot-Extended` are
# permission tokens: the page is still fetched by Googlebot/Applebot for search,
# and the token says whether that content may also feed Gemini / Apple
# Intelligence. Disallowing them is the documented way to opt out of that use
# without dropping out of search.
#
# None of this is enforcement. It is a request that well-behaved agents honour
# and everyone else ignores, and it is NOT access control: anyone with a URL
# still reads everything. If that matters, the answer is authentication.
#
